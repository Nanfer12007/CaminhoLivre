# CaminhoLivre

O CaminhoLivre é uma plataforma de acessibilidade urbana desenvolvida para ajudar pessoas com deficiência, idosos e pessoas com mobilidade reduzida.

## Tecnologias

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security com JWT
- PostgreSQL
- RabbitMQ
- Spring AI
- Docker
- Azure DevOps

## Integração Contínua

O projeto utilizará Azure Pipelines para:

- Compilar a aplicação com Maven.
- Executar testes automatizados com JUnit.
- Publicar os resultados dos testes.
- Gerar o artefato JAR para implantação.

## Implantação

A infraestrutura será provisionada utilizando Azure CLI.

O deploy está planejado para o Azure, dependendo da disponibilidade dos recursos da assinatura.
